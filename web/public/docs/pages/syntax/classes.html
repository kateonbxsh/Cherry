Classes

A class is a template for an object. Classes gather methods that provide functionality for objects. An object is an instance of the class. The data or variables defined within a class are called members of the class.

This is how you would typically define a minimal class

class Player {
  string name;
}
This defines the template for a Player, which is now a type, every instantiated instance of Player will have a field called name of type string. If you want to create an instance of this type, you use the new keyword.

Construct and use

Counter c = new Counter(10);
c.inc();
Standard.println("{}", c.value);

Access and modifiers

Use public, private, and protected deliberately. Keep mutation points narrow; expose methods when invariants matter.
