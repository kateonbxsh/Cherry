Operators

Operators are the symbols and keywords Cherry uses to build expressions: doing arithmetic, comparing values, combining booleans, manipulating bits, checking types, and updating variables.

Operator summary

Cherry groups operators into a few categories. You will see each category with examples below.

  • Arithmetic: +, -, *, /, mod, div, ** (and ^ as an exponent alias)
  • Assignment: =, and compound assignment like +=, -=, *=, /=
  • Comparisons: ==, !=, >, >=, <, <=
  • Logic: and / &&, or / ||, not / !
  • Bitwise: &, |, !| (xor), plus aliases like xor and ^|| (xor alias)
  • Type test: is

Note: Some tokens are punctuation (not operators): ;, :, ,, and quotes (', ").

Arithmetic operators

Arithmetic operators work with numeric values like int and real. They produce a new value, which you can store in a variable or pass to a function.

Addition (+)

Use + to add numbers.

int a = 10;
int b = 3;

int sum = a + b;
Standard.println('sum={}', sum); // 13

In many languages, + is also used for string concatenation. If Cherry supports that, it works like this: 

string s = 'Hi ' + 'there';
Standard.println('{}', s); // Hi there

Subtraction (-)

Use - to subtract one number from another.

int x = 10;

int result = x - 4;
Standard.println('result={}', result); // 6

Multiplication (*)

Use * to multiply numbers.

int x = 6;

int result = x * 7;
Standard.println('result={}', result); // 42

Cherry also supports multiplying a string by an int. The result is the string repeated. 

string a = "a" * 5; // "aaaaa"

Division (/)

Use / to divide numbers.

int x = 10;
int y = 3;

Standard.println('x/y={}', x / y);

/ is a real division. If you are looking for integer division, use the div keyword.

Division by zero throws a DivisionByZeroException.

Remainder (mod)

mod returns the remainder after division. This is commonly used for wrapping logic, checking even/odd values, or building cycles. 

int x = 10;
int y = 3;

int r = x mod y;
Standard.println('remainder={}', r); // typically 1

Integer division (div)

div is used when you want integer division explicitly. 

int x = 10;
int y = 3;

int q = x div y;
Standard.println('quotient={}', q); // typically 3

Exponentiation (**, alias ^)

Exponentiation raises a number to a power.

int x = 2;

Standard.println('pow={}', x ** 8); // 256
Standard.println('pow={}', x ^ 8);  // same, if ^ is an alias

Comparison operators

Comparison operators compare two values and return a boolean. They are most commonly used in if, unless, and loops.

Equals (==)

Standard.println('{}', 10 == 10); // true
Standard.println('{}', 10 == 11); // false

Not equals (!=)

Standard.println('{}', 10 != 11); // true

Ordering (>, >=, <, <=)

Standard.println('{}', 5 > 3);  // true
Standard.println('{}', 5 >= 5); // true
Standard.println('{}', 2 < 1);  // false
Standard.println('{}', 2 <= 2); // true

What can be compared?

Numeric types can be ordered; most other types only support equality. Strings can also be ordered following alphabetical ordering.

  • ints and reals can be compared and ordered.
  • Two class instances A, B are equal if and only if they refer to the same object in memory.
  • Two types T, U are equal if and only if they are mutually (an instance of T can be assigned to U and vice-versa).

Logical operators

Logical operators work with boolean values and also return a boolean. They are used to combine conditions.

AND (and / &&)

boolean a = true;
boolean b = false;

Standard.println('{}', a and b); // false
Standard.println('{}', a && b);  // false

OR (or / ||)

boolean a = true;
boolean b = false;

Standard.println('{}', a or b); // true
Standard.println('{}', a || b); // true

NOT (not / !)

boolean ok = false;

Standard.println('{}', not ok); // true
Standard.println('{}', !ok);    // true

Short-circuit evaluation

Logical and/&& and or/|| are short-circuiting:

  • false && expr does not evaluate expr
  • true || expr does not evaluate expr

This matters when the right-hand side has side effects.

function side = () => { Standard.println('ran'); return true; };

boolean x = false && side(); // prints nothing if short-circuit
boolean y = true  || side(); // prints nothing if short-circuit

Bitwise operators

Bitwise operators work on int values by operating on their binary representation. They are commonly used for flags, masks, and low-level algorithms.

Bitwise AND (&)

int a = 6;  // 110
int b = 3;  // 011

Standard.println('{}', a & b); // 2 (010)

Bitwise OR (|)

int a = 6;  // 110
int b = 3;  // 011

Standard.println('{}', a | b); // 7 (111)

Bitwise XOR (!|, aliases xor, ^||)

int a = 6;  // 110
int b = 3;  // 011

Standard.println('{}', a !| b);   // 5 (101)
Standard.println('{}', a xor b);  // same, alias
Standard.println('{}', a ^|| b);  // same, alias

Bitwise type rules

  • Bitwise operators should only accept integer-like values. Using them with real or string should throw a type error.
  • Cherry’s current operator set does not include shift operators (<<, >>). If you add them later, document them here with examples.

Type test operator

is

The is operator checks whether a runtime value is compatible with a target type. It uses the same assignability logic as variable assignment and function calls. 

any v = 123;

if (v is int) {
  Standard.println('int');
}

if (v is string | int) {
  Standard.println('string or int');
}

Common questions

  • What about any? The check evaluates the actual runtime type inside the any value.
  • What about generics? Decide whether runtime keeps generic metadata (richer checks) or erases it (simpler runtime).
  • What about null? A typical rule is: null is T is false unless T explicitly allows nullability.

Compound assignment and operator overloads

Compound assignment operators combine an operation and an assignment into one step. For example, x += y updates x by adding y.

Example: numeric update

int count = 0;
count += 1; // count = count + 1

Example: overloaded operator update

When the operands are objects, Cherry may use operator overloads. If the type defines an appropriate operator, compound assignment dispatches through it. 

vec += otherVec; // uses operator + if defined for Vec

Nested targets and side effects

In compound assignments, the left-hand side should be evaluated once to locate the final target. This avoids double evaluation of index expressions or getters. 

obj.items[expensive()].value += 1;

Operator precedence and grouping

When you write expressions with multiple operators, precedence decides which parts are evaluated first. Parentheses always make grouping explicit.

Example

int x = 1 + 2 * 3;
int y = (1 + 2) * 3;

In most languages, multiplication happens before addition, so x becomes 7 and y becomes 9. Cherry should document its precedence rules clearly.

Typical precedence (recommended)

  • Exponentiation
  • Multiplication / Division / Modulo / Integer division
  • Addition / Subtraction
  • Comparisons
  • Logical NOT
  • Logical AND
  • Logical OR
  • Assignment

If Cherry differs from these conventions, mention it early and show examples where the result changes.
