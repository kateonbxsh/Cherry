## Built-ins

Cherry has a few built-in types, functions and classes.

### Built-in types

Built-in types are:
- `any`
- `int` underlying C++ `long long`
- `real` underlying C++ `double`
- `string`
- `boolean`
- `type`
- `function`

### Built-in classes

- `Standard`
- `Exception` and children (`TypeException`, `NameException`...)
- `Array<T>`
- `Map<K, V>`
