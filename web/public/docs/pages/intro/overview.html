Cherry Language Overview

Cherry is an interpreted language designed for expressive syntax and robust runtime behavior. It combines classes, generics, functions, lambdas, operator overloading, indexers, dynamic type definitions, and detailed diagnostics.

Main capabilities

  • Object-oriented programming with classes, constructors, methods, static members, access flags, and display stringification hooks.
  • Type system with generics, default type parameters, extends constraints, union-like operators, and dynamic predicate types.
  • Runtime library with Standard, Array<T = any>, and Map<U = string, V = any>.
  • Exception model with stack traces and rich error rendering.
Cherry source files use the .chry extension.
