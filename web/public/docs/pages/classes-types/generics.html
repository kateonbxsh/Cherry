Generics

Generics let you define type families. Build the concept slowly: start with a type parameter, then add defaults, then add constraints, then combine with dynamic type forms.

Generic class basics

class Box {
  public T value;

  public Box(T v) {
    this.value = v;
  }
}

Box a = new Box(5);
Box b = new Box("hello");

Default type parameters

Defaults are applied when omitted, but defaults must be at the end of the type parameter chain.

class Pair {
  public T left;
  public U right;
}

Pair ok = new Pair();

// fail: default in non-last position
// class Bad {}

Constraints with extends

Use extends to require assignability to a base type.

class Repo {
  public T last;
}

Dynamic type patterns

Cherry also supports dynamic type definitions driven by predicates and unions.

type LongName = string x when x.length() > 5 default "sample";
type Optional = T | null;
type StrOrFive = string | 5;

Mental model for partial consumption

If you partially apply generics (for example aliasing A<int> from A<T, U>), consumed parameters are considered fixed and removed from the remaining free parameter list.
