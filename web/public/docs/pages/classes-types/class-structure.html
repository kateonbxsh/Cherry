Class structure

Build classes incrementally: start with fields, add constructor invariants, then add behavior through methods and overloads. This sequence keeps your model coherent.

1) Fields and modifiers

Fields hold state. Modifiers define visibility and mutation rules.

class Account {
  public string owner;
  private real balance;
  public readonly string id;
}

2) Constructor

Use the class name as constructor method and initialize all required state there.

class Account {
  public string owner;
  private real balance;
  public readonly string id;

  public Account(string owner, string id, real opening) {
    this.owner = owner;
    this.id = id;
    this.balance = opening;
  }
}

3) Methods

Methods should preserve class invariants. Prefer method-based mutation for private fields.

public deposit(real amount) {
  if (amount <= 0) throw new ArgumentException("amount must be > 0");
  this.balance += amount;
}

public getBalance() {
  return this.balance;
}

4) Method overloading

Overloading lets one method name accept multiple compatible signatures, as long as overloads are not ambiguous.

public log(string msg) {
  Standard.println("{}", msg);
}

public log(string prefix, string msg) {
  Standard.println("{}: {}", prefix, msg);
}

Success and fail examples

// success
Account a = new Account("Lina", "acc-1", 100.0);
a.deposit(50.0);

// fail: private access from outside
// Standard.println("{}", a.balance);

// fail: readonly write
// a.id = "acc-2";
